# Liste de contrôle « jour J » : Mission Sophie

Version provisoire, à compléter après les tests réels.

## La veille

- [ ] Téléphone NFC chargé à 100 %, chargeur et câble prêts.
- [ ] Dernière version de l'APK installée (`adb install -r …`).
- [ ] Admin › Liaison des tags : un tag lié pour **chaque pendentif utilisé**, plus le **faux badge** et le **Cœur**.
- [ ] Admin › Sauvegarde : liaisons **exportées** (copie sur le PC).
- [ ] Admin › Test de lecture : chaque tag lu un par un, au bon endroit du dos du téléphone.
- [ ] Admin › Contenu : bonne version du contenu, **aucun [crochet]** restant dans les textes.
- [ ] Admin › Contenu › Vérifier les voix : toutes les voix voulues sont ✓.
- [ ] Admin › Prévisualisation › Tester le cri-mètre : le seuil est atteignable en criant toutes ensemble (sinon le baisser dans le contenu).
- [ ] Admin › Réglages › Tests : **simulateur désactivé** (plus de bouton SIM à l'écran).
- [ ] Admin › Partie : **réinitialiser** la partie.
- [ ] Recopie d'écran vers la télé (Smart View, Chromecast) testée, son compris.

## Une heure avant

- [ ] Mode « Ne pas déranger » activé (aucune notification pendant le jeu).
- [ ] Veille automatique de l'écran réglée au maximum (l'appli garde l'écran allumé, mais c'est une sécurité).
- [ ] NFC activé, micro autorisé pour l'appli. Volume média réglé.
- [ ] **Météo choisie** dans Admin › Réglages (☔ Il pleut / ☀ Il fait beau).
- [ ] Cachettes : **faux badge** sur la mezzanine ☔ ou le trampoline ☀ ; **boîte du Cœur** dans la cave ☔ ou près de l'étendage à linge ☀.
- [ ] Lieux : ballon (Rafaleuse), cuisine ☔ ou allée du garage ☀ (Éclipseuse), carte CRISTAL à la chaudière = case C4 du plan (Téléporteuse), bassine sous la pergola (Hydrokinésiste), boîte à récup pour la couronne (Invocatrice).
- [ ] Matériel des épreuves des pouvoirs choisis (voir la fiche des épreuves), et des bonus si le temps le permet.
- [ ] **Cartes-souvenirs** : une seule pile numérotée de 1 à 10, rangée **dans l'ordre des numéros**.
- [ ] Cartes de personnage, pendentifs.
- [ ] Fiche MJ des codes dans la poche (elle ne s'affiche jamais à l'écran).

## Pendant la partie

- Début : chaque fille pose son pendentif (**rassemblement**), puis « Toutes les Gardiennes sont là ! ». Une erreur ? Menu MJ › « Étape précédente » retire le dernier pendentif posé.
- Après chaque épreuve, l'écran indique « carte-souvenir n°X » : remettre la carte X de la pile.
- Joker : la carte de personnage, montrée une fois au MJ (indice, 2 minutes de plus, emprunt d'un pendentif).
- Menu MJ : **appui 3 secondes sur le logo de Sophie**, puis PIN.
- Épreuve bloquée : menu MJ › « Envoyer l'indice », puis « Passer l'étape ». Remettre quand même la carte.
- Cri-mètre qui ne se remplit pas : menu MJ › « Forcer le code / le cri ».
- Pendentif absent ou oublié : menu MJ › « Joker : autre pendentif ».
- Piège trop long : menu MJ › « Valider / passer le piège ».
- Erreur de manipulation : menu MJ › « Étape précédente ».
- Plantage ou écran verrouillé : relancer l'appli › Jeu › **Reprendre la partie**.
- NFC capricieux : poser le pendentif bien à plat, au même endroit, pendant 1 seconde.
- Après la finale : bouton « Épreuves bonus » pour les talents non choisis.

## Cartes-souvenirs et écho final

Les cartes sont remises **dans l'ordre des numéros**, une après chaque épreuve (même passée). À la fin, Sophie rejoue l'écho des pouvoirs réveillés dans l'ordre des épreuves ; les filles reposent leurs pendentifs dans ce même ordre, c'est-à-dire dans l'ordre de leurs numéros. Bouton « Revoir l'écho » à tout moment. Mauvais ordre : blocage de 20 s, puis l'écho est rejoué.
